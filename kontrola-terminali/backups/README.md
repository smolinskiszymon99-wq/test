# Kopie zapasowe (GitHub)

Pliki JSON w tym katalogu powstają z aplikacji (**Ustawienia → Wyślij na GitHub**).

- Nie edytuj ręcznie, chyba że wiesz, co robisz.
- Token PAT **nie** trafia do tych plików — jest tylko w przeglądarce użytkownika.
- Import: **Ustawienia → Pobierz z GitHub** → wybierz zapis.
